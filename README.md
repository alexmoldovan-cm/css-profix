# CSS Profix - Companie de Construcții și Renovări

## Despre Proiect

CSS Profix este un website modern dezvoltat pentru o companie de construcții și renovări din România. Utilizând tehnologii de ultimă generație, site-ul oferă o prezență online profesională și atractivă pentru serviciile companiei.

### Tehnologii Utilizate

- **Framework Principal**: Angular 17
- **Limbaje**: TypeScript, HTML5, CSS3
- **Dezvoltare**: Visual Studio Code
- **Control Versiune**: Git
- **Dependențe**: Node.js, npm
- **Deployment**: Angular CLI
- **Design**: Figma (pentru mockups și design)

## Obiective și Scop

### Scopul Proiectului
Website-ul a fost creat pentru a servi ca platformă digitală principală pentru CSS Profix, oferind:
- Prezentare profesională a serviciilor de construcții și renovări
- Portfolio interactiv cu proiecte realizate
- Informații despre companie și echipă
- Canal de comunicare cu potențialii clienți

### Public Țintă
- **Proprietari de Case**: Persoane care caută servicii de renovare
- **Dezvoltatori Imobiliari**: Pentru proiecte de construcții la scară mare
- **Proprietari de Spații Comerciale**: Pentru renovări și amenajări de spații comerciale
- **Arhitecți și Designeri**: Pentru colaborări în proiecte

## Funcționalități Principale

### 1. Design Modern și Responsive
- Interfață intuitivă și atractivă
- Adaptabilitate completă pentru toate dispozitivele
- Efecte vizuale moderne și animate
- Timpi de încărcare optimizați

### 2. Portfolio Interactiv
- Galerie de proiecte cu imagini de înaltă calitate
- Descrieri detaliate ale proiectelor
- Navigare fluidă și interactivă
- Optimizare pentru încărcare rapidă a imaginilor

### 3. Informații Corporative
- Prezentare detaliată a companiei
- Profiluri ale echipei de management
- Misiune și viziune corporativă
- Istoricul și realizările companiei

### 4. Optimizare și Performanță
- SEO optimizat pentru piața românească
- Timpi de încărcare rapizi
- Accesibilitate conform standardelor WCAG
- Performanță optimizată pentru toate browserele moderne

## Instalare și Rulare

```bash
# Clonare repository
git clone https://github.com/alexmoldovan-cm/css-profix.git

# Instalare dependințe
npm install

# Pornire server de dezvoltare
ng serve

# Accesare aplicație
http://localhost:4200
```
